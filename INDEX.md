## How to use this index

This index is sparse during the sweep phase and fills in as the page builder produces pages. For the current state of Round 1 verdicts (unchanged, English-only) see https://github.com/keyserfaty/aging-synthesis/blob/main/INDEX.md.

For methodology and disagreement protocol, see `methodology-multilingual.md`. For the locked predictions, see `meta/expected-discordances.md`. Disagreements should be raised as GitHub issues, not by silently editing.

---

## What this database is not

- Not personal medical advice. Verdicts are population-level evidence summaries.
- Not a translation service. The translations recorded here are reference-only and Q-flagged for quality.
- Not free of judgment calls — every verdict is a calibration claim defensible against the methodology and anchors. Disagreements should be raised via the question-resolver process.
